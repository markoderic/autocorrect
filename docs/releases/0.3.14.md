# AutoCorrect 0.3.14 — safer corrections, notarized download

This release reduces harmful automatic replacements, improves reviewable grammar and punctuation suggestions, and replaces the old unnotarized public download with a Developer ID signed, Apple-notarized package.

- Protect unfamiliar names within prose and regional English spellings.
- Defer competing word guesses instead of silently choosing a different meaning. Clear spelling repairs and custom replacements continue to work.
- Add narrow grammar rules, protect quoted text and error strings, reject unsupported wording changes, and support safe interior punctuation spacing and contraction apostrophes.
- Include earlier source improvements since 0.3.7, including sentence suggestions, continued-typing Undo, spelling indicators and contextual invitation fixes.

The same-host spelling comparison reduced wrong automatic replacements from 186 to 96 across 4,097 single-target typos. Exact corrections fell from 3,521 to 3,400; misses rose from 375 to 586. This is a deliberate safety/coverage tradeoff. Separate sentence testing improved correct grammar fixes from 17 to 26 of 65 eligible errors and punctuation fixes from 2 to 10 of 42. These are existing regression corpora, not fresh held-out or overall English accuracy. [Full report](../ACCURACY-IMPROVEMENTS-0.3.14.md).

Validation: 368 Swift tests executed, 365 passed, three gated evaluations skipped; six release-script checks and 25 scorer checks passed. Gated accuracy audits were run explicitly. Fallback configuration and both release architectures compile. Physical typing across apps, another-Mac first launch and Intel runtime remain open; this is a preview, not 1.0.

Apple notarization: Accepted; ticket stapled and validated. The final extracted ZIP passed strict signature and Gatekeeper verification (`Notarized Developer ID`), plus macOS distribution checks. Download this new release instead of reusing an old ZIP. The normal macOS first-open confirmation and Accessibility/Input Monitoring permissions still apply; no security bypass is required.
