# AutoCorrect demo

An 18-second **illustrated product demo**, authored and rendered with Higgsfield's native Higgsedit video-editing workflow. It is not a recording of a real typing session and is not evidence of cross-app compatibility.

- [MP4](autocorrect-demo.mp4): 1280×720, 24 fps, H.264, silent. Best attachment for a social post.
- [GIF](autocorrect-demo.gif): 800×450, 12 fps, looping. Embedded in the repository README.
- [Poster](autocorrect-demo.png): still from the typo-correction scene.
- [Contact sheet](autocorrect-contact-sheet.png): review of the major scenes.
- [Editable composition](autocorrect-demo.jsx): native Higgsedit source. The output directory is `/home/user` for the Higgsfield sandbox; adjust paths for another environment.

The scenes illustrate ordinary typo correction, a built-in abbreviation, and respecting a manually rewritten correction at the same location. The `homebred` example illustrates replacing an unwanted correction, not a claim that the current version automatically changes `homebrew` to `homebred` (that false positive is now separately guarded).

Render: `higgsedit build autocorrect-demo.jsx`. No user documents, messages, or typing were uploaded. All displayed text was authored for this demo. The GIF and PNG exports were packaged in the same Higgsfield sandbox. No LinkedIn post was sent or published.
